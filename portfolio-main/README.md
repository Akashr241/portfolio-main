# Akash R — Developer Portfolio

Personal portfolio for Akash R, showcasing Java backend and full-stack development work, projects, experience, skills, and ways to connect.

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Deployed on Vercel

## Sections

The page is assembled from components in `src/sections/`:

- Hero
- Quick Highlights
- About
- Experience
- Skills
- Projects
- Achievements
- Problem Solving
- Hackathon
- Education
- GitHub
- Resume CTA
- Contact
- Footer

## Run locally

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

## Edit content

Portfolio content lives in `src/data/*.ts`. Resume PDFs are served from `public/resumes/`.
